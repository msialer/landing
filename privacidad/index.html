Política de privacidad

Última actualización: 9 de noviembre de 2026.

Responsable. Este sitio, mauricio.sialer.com, es la página personal de Mauricio Sialer, quien es responsable de él.

Qué datos se recogen. El sitio no tiene formularios, analítica ni cookies, y no te pide datos personales. Al visitarlo se generan solo estos datos técnicos:

  • Vercel, el proveedor de hosting, registra la dirección IP, el navegador, la página visitada y la hora de cada visita.
  • Las páginas cargan tipografías de Google Fonts y estilos del CDN de Tailwind. Para entregarlos, Google y Tailwind reciben tu dirección IP y los datos de tu navegador. No ponen cookies.
  • Si eliges idioma, tu preferencia se guarda en tu propio navegador (localStorage). La página de inicio también lee el idioma de tu navegador para mostrarte la versión en español. Esa información no sale de tu navegador.

Para qué se usan. Los registros del hosting sirven solo para que el sitio funcione, sea seguro y se puedan resolver problemas técnicos. Mauricio Sialer no usa estos datos para perfilarte ni para publicidad.

Con quién se comparten. Los datos no se venden. Fuera de los proveedores mencionados, que los reciben al entregar el sitio, no se comparten con nadie.

Contacto. Si tienes alguna pregunta sobre esta política, escribe a hello@sialer.com.
